隐私政策

最后更新：2026 年 10 月 7 日

本应用不向开发者收集、上传或共享任何个人数据。本应用没有开发者运营的服务器，不会把你的任何信息发送给我们。

本应用在本机保存的内容

内容存放位置用途
GitHub 授权令牌macOS 钥匙串（应用沙盒容器内）代表你调用 GitHub API 与建立终端连接
实例运行观察记录与用量统计应用沙盒容器内的 Application Support/CodespacesDesk/usage.json本地展示用量与费用估算
界面偏好（外观、字号、提醒阈值等）应用沙盒容器内的偏好设置记住你的设置

以上数据全部保存在你的 Mac 上，随应用卸载或删除容器目录即可清除。断开 GitHub 连接会移除钥匙串中的令牌。

网络通信

本应用的网络通信只发生在你的设备与下列服务之间，不经过开发者：

服务说明
GitHub（github.com 及 api.github.com）使用你自己的授权令牌读取 Codespaces 列表、启动 / 停止 / 新建 / 删除实例。令牌权限由 GitHub 网页授权流程决定。
GitHub Codespaces 隧道服务建立终端会话时，本应用内置的 GitHub CLI 会通过该服务建立到你自己实例的 SSH 隧道。
Apple App Store处理内购、订阅与恢复购买。支付由 Apple 处理，本应用不接触你的支付信息。

本应用不含任何分析、统计、广告或崩溃上报 SDK。

权限说明

权限用途
网络（出站）访问上述服务。
网络（本地监听）建立终端会话时，在本机回环地址 127.0.0.1 监听一个临时端口，用于把该端口桥接到 SSH 隧道。该端口不对外网开放，不接受外部连接，并随会话结束释放。
钥匙串保存 GitHub 授权令牌。
本地通知（可选）需你手动开启。在运行时长或费用达到你设定的阈值时提醒。

第三方

本应用连接 GitHub 服务，你对 GitHub 的使用受 GitHub 隐私声明 约束。本应用与 GitHub 无官方关联，未获 GitHub 背书。

应用内置的 GitHub CLI（gh）为 MIT 许可的开源软件，许可证全文随应用包一同分发。

儿童隐私

本应用不面向儿童，也不会有意收集儿童的任何信息。

政策变更

本政策如有变更，将更新本页顶部的日期。由于本应用不收集数据，变更通常仅涉及说明文字的澄清。

联系方式

如有隐私相关问题，请通过 App Store 产品页的「App 支持」链接联系我们。
