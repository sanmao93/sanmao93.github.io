系统要求
  • macOS 14 或更高版本
  • Apple 芯片 Mac
  • 使用真实云端实例需要 GitHub 账号，且账号具备 Codespaces 权限

常见问题

终端连不上怎么办？

终端通过 GitHub CLI 建立到实例的 SSH 隧道，需要实例镜像内包含 sshd（GitHub 官方默认镜像已包含）。对已停止的实例打开终端时，实例会先启动，可能需要 1 到 2 分钟。若公司网络要求走代理，请确认代理允许访问 GitHub 的隧道服务。

实例费用是怎么算的？

云栈显示的用量是本机观察值，按相邻两次成功同步的间隔累加，不是 GitHub 官方账单。Mac 休眠、断网或应用退出期间不补算。计算费用按 $0.09 / 核时估算，未抵扣免费额度，不含存储、预构建和税费。已停止的实例仍可能产生存储费用。请以 GitHub 账单为准。

Pro 包含 GitHub 的计算费用吗？

不包含。云栈 Pro 只解锁应用内的多实例功能，GitHub Codespaces 的计算与存储费用始终由你的 GitHub 账号承担。

如何取消订阅？

在 App Store 中管理：打开 App Store → 账户 → 订阅，或访问 apps.apple.com/account/subscriptions。取消后当前订阅周期结束前仍可使用 Pro 功能。

换电脑后怎么恢复购买？

在同一 Apple 账户下登录 App Store，打开云栈的套餐页面，点击「恢复购买」。

断开 GitHub 连接会删除我的实例吗？

不会。断开连接只移除本机保存的授权令牌，云端实例继续运行。要停止实例请在应用内操作，或到 GitHub 网页处理。

数据存在哪里？

全部在本机。GitHub 令牌在 macOS 钥匙串，用量记录在应用容器内。详见 隐私政策。

应用和 GitHub 是什么关系？

云栈是独立开发的第三方客户端，与 GitHub 无官方关联，未获 GitHub 背书。
